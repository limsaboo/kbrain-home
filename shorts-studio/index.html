고르면 아래 칸이 자동으로 채워져요. 고쳐서 써도 됩니다.

1어느 연구소 영상인가요?

2첫 화면 문구

영상 맨 처음 3초에 크게 나와요. *별표*로 감싼 말은 노랗게 강조돼요. 줄을 나누려면 엔터를 누르세요. (40자 이내)

3장면 문구

장면은 빈 줄로 나눠요. 한 장면은 3.4초 나옵니다. 1~6장면, 장면당 60자 이내. 마지막에 "프로필 링크로 오세요" 장면은 자동으로 붙어요.

4그림 고르기

영상 위쪽에 움직이는 그림이 직접 그려져요.

5근거 (신뢰의 핵심)

링크가 없는 과학적 주장은 영상으로 만들어지지 않아요. 연구소의 신뢰를 지키는 규칙입니다.

6올릴 때 쓸 설명

👀 미리보기 (대략적인 모양)

그림은 영상에서 직접 그려져요. 여기서는 이모지로 대신 보여줍니다. 글자 크기와 줄바꿈은 영상에서 자동으로 맞춰져요.
만드는 데 보통 2~4분 걸려요. 앱을 닫아도 서버가 계속 만듭니다. 끝나면 “결과”에서 받으세요.

🔗 서버 연결 (처음 한 번만)

이 정보는 이 휴대폰 안에만 저장되고 다른 곳으로 보내지 않아요. (GitHub 서버로만 전송)

📱 홈 화면에 설치

크롬 오른쪽 위 ⋮ 메뉴 → “홈 화면에 추가” 또는 “앱 설치”를 누르세요.

🧭 열쇠(토큰) 만드는 법

  1. GitHub 접속 → 오른쪽 위 내 사진 → Settings
  2. 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access에서 Only select repositories를 누르고 제작 저장소 하나만 고르기
  4. Permissions: Contents = Read and write, Actions = Read-only
  5. 만들어진 열쇠를 복사해 위 칸에 붙여넣고 저장 → 연결 시험
