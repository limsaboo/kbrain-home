# 한국뇌심리연구소 홍보·마케팅 실행 계획
### 유튜브 쇼츠 · 블로그 · 신간도서 출간 연계
작성: 클박사 (실행 총괄) — 채박사 업무분장 포함

> 이 문서는 한국뇌심리연구소 Project Bible에 따라 작성되었습니다.

---

## 1. 목표

- 홈페이지 순 방문 (현재 91명 누적) → **월 1,000명** 규모로 성장
- 5종 진단시스템 무료체험 유입 확대
- 신간 《사람을 이해하는 법, 뇌를 알면 됩니다》 출간 사전 인지도 확보
- 회원가입·추천인·마일리지 제도(이미 구축됨)와 홍보 콘텐츠를 자연스럽게 연결

---

## 2. 콘텐츠 4대 축 (혼용 금지, 각각 역할 분리)

| 축 | 핵심 메시지 | 주 채널 | 목적 |
|---|---|---|---|
| ① 연구소 브랜드 | "우리는 사람을 평가하지 않고 이해합니다" | 유튜브 쇼츠, 인스타 | 신뢰·인지도 |
| ② 5종 진단시스템 체험형 | "3분이면 내 뇌 성향을 알 수 있어요" | 쇼츠, 블로그 | 무료검사 유입(전환) |
| ③ 신간 도서 티저 | "곧 나옵니다 — 뇌를 알면 사람이 보입니다" | 블로그, 인스타 | 출간 사전 기대감 |
| ④ 시니어인지건강 | "우리 부모님 뇌 건강, 3분 체크" | 쇼츠(별도 타겟) | 시니어센터 유입 |

**원칙**: 하나의 영상/글에 4개 축을 섞지 않는다. 이미 확립된 "영상별 역할 분리 금지" 브랜드 원칙과 동일하게 콘텐츠에도 적용.

## 3. 포맷별 전략

### 유튜브 쇼츠 (채널: 뇌과학 임찬우TV)
- **길이**: 30~60초, 3초 안에 후킹 문장 노출 (예: "이거 5초 만에 대답 못 하면...")
- **주 3회 업로드** 목표 (월·수·금)
- 매 영상 하단 고정 댓글에 무료검사 링크 + 추천인 코드 안내
- 시리즈화: "뇌성향 30초 테스트" 시리즈, "이런 분 계신가요?" 공감형 시리즈

### 블로그 (네이버)
- SEO 키워드 타겟: "뇌성향검사", "부부 뇌궁합", "시니어 인지검사", "임찬우 소장"
- 뇌궁합=상단퍼널(무료·바이럴), 뇌심리성향=하단퍼널(유료·상담 연결) — 기존 전략 유지
- 주 2회 발행

### 인스타그램 (@brainsaboo)
- 쇼츠 재활용 + 카드뉴스(캐러셀) 형태로 진단 결과 예시 공유
- 스토리에 "DM으로 무료쿠폰 개별 전달" (기존 정책 유지, 코드 공개 금지)

## 4. 신간 도서 연계 특별 캠페인

**《사람을 이해하는 법, 뇌를 알면 됩니다》 출간 전 4주 카운트다운**

| 주차 | 콘텐츠 |
|---|---|
| D-28 | "곧 공개됩니다" 티저 쇼츠 (표지 실루엣만) |
| D-21 | 저자(임박사) 인터뷰 쇼츠 — "왜 이 책을 썼는가" |
| D-14 | 책 속 4가족 에피소드 중 1개 미리보기 (블로그) |
| D-7 | 사전예약 오픈 + 사전예약자 한정 굿즈/마일리지 안내 |
| D-Day | 출간 소식 전 채널 동시 발행 |

**연결고리**: 책 → QR → 홈페이지 뇌심리성향 미니검사(?mode=) → 회원가입 → 무료쿠폰 — 이미 구축된 QR 전략을 그대로 재사용.

## 5. 업무 분장 (클박사 제안)

| 담당 | 역할 | 산출물 |
|---|---|---|
| **채박사 (ChatGPT)** | 카피라이팅·스토리텔링 전문 | 쇼츠 대본 15개/월, 후킹 제목 후보, 블로그 SEO 원고, 도서 티저 카피, 브랜드 톤 일관성 감수 |
| **클박사 (Claude)** | 기술 구현 전문 | 콘텐츠별 전용 추적 링크(UTM) 생성, 쇼츠용 자막·썸네일 템플릿 코드, 방문자 통계 대시보드 확장(유입경로별 분석), 랜딩페이지 제작 |
| **임박사** | 최종 승인·촬영 출연 | 대본 컨펌, 실제 촬영/녹화, 최종 발행 |

**협업 흐름**: 채박사가 대본 초안 작성 → 클박사가 UTM 추적 링크·통계 세팅 → 임박사가 촬영·발행 → 클박사가 성과 데이터 취합 → 채박사가 다음 콘텐츠 방향 조정.
