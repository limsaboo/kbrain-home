# 📋 BHC v3 문제 및 보기 재설계 (기존 시스템 기반)

## 원칙
1. **2단계 구조**: 자극(이미지) → 질문(명확한 문장)
2. **4개 선택지**: 모두 선택 가능하도록 명확화
3. **실제 이미지 또는 텍스트**: Unsplash 대신 로컬/GitHub 이미지
4. **일관성**: 모든 문항이 동일한 난이도/명확성
