# 📎 그림 투사 방식 이미지 분석 프레임워크
## 뇌과학 기반 해석 가이드 (잼박사(재미나이) 자문)

### 핵심 원리
- 투사 검사: 무의식적 내면을 이미지로 표현
- 뇌과학 메커니즘: DMN, Amygdala, MNS, TPJ, DLPFC 통합
- 4가지 영역: 자연물/상징, 관계/상황, 추상/비구조, 색채/감정

### 영역 1: 자연물 및 상징 이미지
**뇌과학:** DMN + 두정엽 신체 지도 (Homunculus)

| 프롬프트 | 뇌과학적 해석 |
|---------|-------------|
| 튼튼한 고목 | 해마-전두엽 연결성, 높은 자아 강도 |
| 폭풍 속 흔들리는 나무 | 편도체 과활성, 자아 방어 유약 |
| 온화한 오두막 | 옥시토신/세로토닌, 안전지대 |
| 문 닫힌 요새 | 전두엽 방어, 경계심 높음 |
| 사막의 선인장 | HPA 축 스트레스, 공격적 방어 |
| 울창한 공터 | DMN 회복 탄력성 |
| 메마른 대지 | 도파민/세로토닌 저하, 고갈 |
| 거대 절벽 | 경직된 사고, 변화 저항 |
| 시드는 꽃밭 | mPFC 부정적 자기참조, 자존감 저하 |
| 맑은 호수 | 전두엽-변연계 정서 조절 우수 |

### 영역 2: 관계 및 대인 상황 이미지
**뇌과학:** MNS(거울신경세포) + TPJ(측두-두정 접합부)

| 프롬프트 | 뇌과학적 해석 |
|---------|-------------|
| 등 돌린 두 인물 | TPJ 회피적 추론, 회피형 애착 |
| 격렬한 대립 | 편도체/ACC 과활성, 분노 조절 문제 |
| 문 두드리는 사람 | 애착 손상, 수용 갈망 |
| 창밖 바라보는 인물 | DMN 미래 지향, 탈출 욕구 |
| 무리 속 소외된 인물 | 사회적 통증 회로 활성, 지지 부재 |
| 손잡고 거니는 연인 | 옥시토신 분비, 안전형 애착 |
| 아이 보살피는 어머니 | 보상회로 활성, 돌봄 욕구 |
| 인물 뒤의 거대한 그림자 | 편도체 무의식적 위협, 권위 불안 |
| 앞을 보며 나아가는 무리 | MNS 집단 동기화, 소속감 |
| 가면 쓰고 대화하는 두 인물 | DLPFC 과도한 억제, 페르소나 |

### 영역 3: 추상 및 비구조화 이미지
**뇌과학:** DLPFC(외측전두엽) + 복측시각경로

| 프롬프트 | 뇌과학적 해석 |
|---------|-------------|
| 대칭적 잉크 반점 | DLPFC 작업기억 정상, 현실 검증력 우수 |
| 파편화된 기하 조각 | 정보 통합 실패, 강박적 세부 집착 |
| 흩어진 무형 잉크 | 변연계 억제 실패, 자유부동 불안 |
| 색 엉킨 불규칙 추상 | ACC 자극 과부하, 충동 조절 어려움 |
| 나선형 소용돌이 | 전두엽 통제력 상실, 우울적 침체 |
| 날카로운 가시 추상 | 편도체 투사적 공격성, 과각성 |
| 요동치는 곡선의 흐름 | 뇌 가성성, 정서 유연성 우수 |
| 복잡하게 엉킨 선들 | 집행 기능 과부하, 인지적 블로킹 |
| 미로 같은 기하 구조 | 좌뇌 문제 해결, 통제 욕구 |
| 관찰하는 눈 반점 | TPJ 과잉 민감, 자의식 과비대 |

### 영역 4: 색채 및 감정 이미지
**뇌과학:** 시상(Thalamus) → 시상하부 및 자율신경계 직접 전달

| 프롬프트 | 뇌과학적 해석 |
|---------|-------------|
| 폭발하는 붉은/주황색 | 교감신경계 극대, 도파민 활성 |
| 고요한 딥 블루 | 부교감신경계, 세로토닌 안정감 |
| 스며드는 검은/회색 | 뇌 에너지 저하, 정서적 마비 |
| 초록/노란색 따뜻함 | 긍정 정서 회로, 희망감/활력 |
| 몽환적 보라/검은색 | DMN 비현실 탐색, 현실 회피 |
| 명암 극명한 무채색 | ACC 이분법적 사고, 극단 정서 |
| 채도 낮은 회색조 | 방어적 억제, 감정 불능증 |
| 부드러운 파스텔 | GABA 활성, 심리적 안전 요구 |
| 빛나는 골드/화이트 | 보상 예측, 높은 포부 |
| 붉은색/파란색 충돌 | 자율신경 불균형, 내적 갈등 |
